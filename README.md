# Muhammad Abubakar — Personal Portfolio

Welcome to my personal portfolio repository! This is a modern, high-fidelity portfolio website built to showcase my journey as a Software Engineer, Full-Stack Developer, and Cybersecurity Researcher.

It features a responsive developer-focused dark-theme design, dynamic physics-based 3D graphics, an interactive bash terminal emulator, and custom card-flip animations.

---

## 🚀 Key Features

*   **Interactive 3D Physics Lanyard Card**: An interactive 3D ID badge powered by React Three Fiber and Rapier that swings and reacts to mouse drag/movement.
*   **Bash Terminal Emulator**: A simulated console that dynamically prints my developer profile, skills, and current focus with realistic typing animations.
*   **Custom Projects Gallery**: Card components using a custom `BorderGlow` component that shifts glow color and flips on hover to reveal tech stacks and project links.
*   **Tech Stack Ticker**: A smooth, infinite-scrolling marquee exhibiting my core technologies and developer tools.

---

## ⚙️ Getting Started

### Prerequisites

Make sure you have Node.js (v18+) and npm installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Muhammad-Abubakar18/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.
